# Community Library Management (React + Vite)

A responsive, browser-based library management system built with React, Vite, and localStorage.

## Run the project
npm install
npm run dev

## Features
- Dashboard with collection stats
- Book management (add, update, delete)
- Transactions (borrow, return, stock)
- User management with login
- React Router navigation
- Responsive UI with CSS
